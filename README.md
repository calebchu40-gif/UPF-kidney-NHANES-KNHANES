# UPF intake and kidney health

R code for the NHANES 2007–March 2020 and KNHANES 2019–2024 analyses.

1. Use Linux, R 4.5.3, the package versions shown by `Rscript Analysis_code.R --packages`, and `7zz`, `7z` or `bsdtar` for USDA archive extraction. Install Arial for matching plot typography. The full analysis uses 14 parallel KNHANES imputation workers and substantial memory.
2. Obtain the 2019–2024 ALL and 24RC SAS files from [KNHANES](https://knhanes.kdca.go.kr/). Its download form requires your name, affiliation, email and agreement to its terms. Extract the 12 files (`hn19_all.sas7bdat`, `hn19_24rc.sas7bdat`, …, `hn24_24rc.sas7bdat`) into `data/knhanes/`.
3. Run from this folder:

```sh
Rscript Analysis_code.R --all
```

Missing NHANES and USDA FPED files are downloaded automatically from official sources; existing files are checked against the study's SHA-256 hashes. A changed official release stops the run rather than silently changing the analysis. Keep the two files in `classifications/` beside the R script; they contain the study-specific food classifications. All other settings and analysis tasks are embedded in the R script. Results are written to `run/regenerated/`; the other `run/` folders hold intermediate calculations and execution logs. Figures are regenerated in R; their typography/layout may differ from the submitted figures. Figure 1 is a study schematic and is not generated by this code.

Optional: `--download` downloads NHANES/FPED without analysis; `--check-data` verifies all local data; `--check` checks R syntax. Use `--raw-knhanes=DIR`, `--raw-nhanes=DIR`, `--fped=DIR`, `--official-xpt=DIR` or `--work=DIR` to change directories. Use a fresh output directory for a new analysis.
